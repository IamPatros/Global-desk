# Global Desk

World news and markets, explained from zero. Updated at 10:00 and 20:00 Warsaw time.

Live site: https://iampatros.github.io/global-desk/

- `index.html` – the whole site (one page).
- `data/index.json` – list of editions, newest first.
- `data/editions/<id>.json` – one file per edition.

Editions are written automatically by a scheduled Claude task.
